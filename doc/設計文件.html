1. 總覽與關鍵數字

這是一個在自製 PCB 上的三相 BLDC/PMSM 驅動，是後代的前一代產品。MCU 為 STM32F103C8T6（Cortex-M3，沒有 FPU），驅動 IC 與後代相同是 DRV8317H（3x PWM 模式），馬達與電源也和後代相同。和後代最大的差別是位置感測器：這一代用 AS5600 磁編碼器，經 I2C 讀 12-bit 角度（後代是 MT6835，ABZ + SPI）。這一代另外有 CAN Bus 指令介面。

控制架構與後代相同：速度 PI → Iq PI → 反 Park → SVPWM，Id 環目標 0；位置模式是後代的串級（位置 P → 速度 PI），另外保留舊程式的 MIT（彈簧 + 阻尼直接算 Iq），以 SET POSTYPE 切換。FOC 在 TIM1 觸發的 ADC injected 轉換完成中斷內執行，電流環 20 kHz、以定點數計算；速度估測、速度環與位置環以浮點、每 4 次中斷算一輪（5 kHz）。文字指令（UART 與 SWD 信箱）、高速擷取的欄位格式、swd_if 結構都與後代相同。

每次 FOC 中斷的計算（main.c Foc_AdcIsr() / Foc_Step()）

  1. 讀 ADC1->JDR1、JDR2（CH1、CH2）；I2C2 空閒時啟動下一筆 AS5600 的 DMA 讀取（AS5600_Kick()）。
  2. 角度：AS5600 有新的一筆時，count = ((zero_raw − raw) & 4095) × 16（方向見問題 #18），相鄰兩筆的差以 int16 累加到多圈位置 pos_count，也累加到速度估測用的 Δcount、Δt。
  3. 電角度：讀值從讀完到現在經過的時間以目前速度外插（最多 1 ms），θe = 7 × count 取 16 bit，sin / cos 以 256 格的 Q15 表加線性內插（sin_lut.c）。
  4. 時槽（每 4 次中斷一輪，浮點）：0 = 速度估測（Δcount ÷ Δt，再過一階低通 VELTF）；1 = 速度目標與目標權重；2 = 速度 PI 或 MIT，更新 Iq 命令；3 = 串級的位置 P。
  5. 電流（定點）：i = adc × 16 − bias；可選的相電流低通（IPHLPF）；Clarke Iα = CH1、Iβ = (2·CH2 + CH1)/√3；Park；可選的 dq 低通（IDQLPF）。
  6. 電流環測試（ITEST 進行中，Itest_Process()）：檢查過電流（|Id| 或 |Iq| > 2 A）、轉速（> 40 圈/秒）與剩餘時間，再依 A / B 準位給 Iq*、Id*（電流步階）或直接給 vq、vd（電壓步階，不經過 PI）。測試期間時槽 2 不跑速度 PI。
  7. 電流 PI（PiFix，Q16 增益、int64 積分，算法同 PIDController_run() 的 P + I）：vq = PI(Iq* − Iq)、vd = PI(Id* − Id)，Id* 平時是 0（IDLOOP 0 時 vd = 0，電流步階時 Id 環一定啟用）。
  8. 反 Park，Svpwm_Counts()：三相、min-max 零序注入置中、限幅在 0 ~ ARR，都是整數。算式與後代的 Svpwm() 相同（duty = (U + 5 − (Umax+Umin)/2) × 0.1），duty 用到完整的 0 ~ 100 %。
  9. 高速擷取（Log_Sample()），以整數累加，存一筆時才換算成後代的欄位比例。

PI 增益、電流偏置、低通與目標權重的係數，由主迴圈每一輪呼叫的 Ctrl_Sync() 從浮點參數換算（中斷內不做除法），所以 SET 最慢 5 ms 後生效。

開環定向 SetAng() 與 ALIGN

同後代：六扇區開環電壓向量，強度 fullTime = 0.2（duty 偏差），比較值以 ARR 為滿刻度。ALIGN（開機時、或指令）：SetAng(0) 後等 500 ms，平均 32 筆 AS5600 讀值當零點 zero_raw，FOC 中斷下一次從單圈角度重新起算多圈位置、位置目標設為目前位置。轉速高於 1 圈/秒 時不接受（[ALIGN] ERR SPEED）。

9. 啟動流程

  1. HAL_Init → SystemClock_Config（72 MHz）→ GPIO、DMA、ADC1、CAN、I2C2、USART1、TIM1、TIM2、I2C1 初始化。
  2. Swd_Init()；由 TIM1 設定算出 PWM 頻率（20 kHz）與 FOC 頻率；啟動 TIM2（micros()）與 DWT 週期計數器；初始化 PID 預設值。
  3. AS5600：清除 I2C2 匯流排（GPIO 送 SCL 脈衝與 STOP，再重新初始化 I2C2），讀一次 ANGLE；讀出並回報 [AS5600] STATUS=… AGC=… CONF=… ZPOS=… MPOS=…。
  4. ADC 校正，啟動 injected 轉換與 JEOC 中斷；TIM1 比較值設 0，啟動 CH1~4。從這裡開始每個 PWM 週期都會進 FOC 中斷（FocDo = 0 時只讀 ADC 與啟動 AS5600 讀取）。
  5. DRV8317 設定：GAIN → Hi-Z、SLEW = High、PWM_ACTIVE = Low、nSLEEP Low → 10 ms → High，等 250 ms（同後代）。
  6. 電流偏置：256 筆平均，每筆間隔 1 ms；Ctrl_Sync()。
  7. PWM_ACTIVE = High；ALIGN（約 0.55 秒），回 [ZERO] ALIGN（讀不到角度時是 [ZERO] ERR ANG）。
  8. CAN filter、啟動 CAN、RX FIFO0 中斷，印 HAL_CAN1_Star1 is HAL_OK（沿用舊程式）。
  9. FocDo = 1，力矩模式（MODE 5）、IQREF = 0（2026-10-15 依作者決定由速度模式 0.1 圈/秒 改過來）；啟動 USART1 RX 中斷，進入主迴圈。

從上電到閉環約 1.1 秒（同後代）。舊程式開機時讀 EEPROM 的 angShift 與 exf_map，這一版都不讀（第 11 節）。

#18 AS5600 讀值增加的方向和磁場 CH1→CH2→CH3 的旋轉方向相反

電流環正常之後，照舊程式的方向（電角度 = 7 × 讀值）給正的 Iq，轉子往負方向走了約 19 度就停住：估測的電角度與實際的電角度以兩倍的速度分開，誤差到 90 度時力矩變成 0（Iq 0.7 A、電壓 2.7 V，全部是電阻壓降）。角度改成 zero_raw − 讀值（ENC_DIR = −1）之後 0.1 圈/秒 只要 25 mA。

這樣的正轉（SET SPEED > 0）從軸端看是逆時針，作者確認與後代相同（2026-10-14）。舊程式照讀值的方向算電角度，在電流讀值為 0（#1）、電流環變成電壓命令頂到限幅的狀態下仍能轉，但力矩與方向的關係並不正確；舊程式開機的速度目標是負的（−4 rpm），可能與此有關。

#19 nFAULT（PA5）運轉正常時也一直是 Low

以 SWD 讀 GPIOA IDR，PA5 在運轉、STOP、BRAKE 時都是 0；把 PA5 暫時改成內部上拉輸入仍然是 0，表示有東西主動拉低（不只是沒有上拉電阻）。DRV8317 的 nFAULT 是開汲極輸出，Low 代表有故障或警告，但馬達運轉正常、電流量測正常。可能是故障旗標閂鎖住了（例如上電時的欠壓）、或 PA5 實際接到的不是 nFAULT。程式不使用 nFAULT，否則會一直停機。需要量測硬體確認。

#20 HAL_ADC_IRQHandler() 在第一次 injected 轉換後就關掉 JEOC 中斷

F1 HAL 判斷「injected 由外部觸發，但 regular 是軟體觸發、而且不是連續模式」時，會認為之後沒有轉換而關閉 JEOC 中斷（stm32f1xx_hal_adc.c）。所以 ADC1_2_IRQHandler() 的 USER CODE 內先檢查 JEOC、清旗標、呼叫 Foc_AdcIsr() 後直接 return，不經過 HAL。CubeMX 重新產生程式碼時這段在 USER CODE 內，不會被覆蓋。

#21 連結時 --wrap 搭配 qfplib_wrap.s 的除錯資訊，ld 會當掉

Debug（-g3）建置時 ld 回傳 exit status 5、沒有任何訊息（GCC 13.3.1，STM32CubeCLT 1.18.0）；MinSizeRel（沒有 -g）正常。拿掉 qfplib_wrap.s.obj 的除錯資訊就能連結，所以 CMakeLists.txt 對這個檔案加 -g0。

#22 UART 路徑沒有實機測試

測試時 USB-UART（COM32）沒有接到這塊板子，所有指令、擷取與調參都是經 SWD 信箱（swd_if）做的。UART 與 SWD 共用同一個 Cmd_Exec()，但 UART 的接收中斷、Cmd_Reply() 的阻塞傳送、LOG / LOGQ 的二進位傳送、後代的 log_capture.py / step_capture.py 在這一代都還沒有實際跑過。已確認 USART1 的暫存器設定正確（115200、TX 啟用、PB6 為 AF 輸出、USART1 remap）。

#23 12-bit 角度的低速限制

AS5600 一個 LSB 是 0.088 度（16 count），約每 100 µs 一筆。0.1 圈/秒 時約 2.4 ms 才變一個 LSB，速度估測要靠低通（VELTF）平滑，速度環的增益因此受限。

17. 指令與後代的差異

指令的格式、回應前綴與後代的 doc/serial指令.html 相同（一行一個、不分大小寫、最長 31 字元；UART 115200 8N1，或 SWD 信箱）。以下只列差異。

指令 / 參數這一代
STOP、BRAKE、RUN、ALIGN、POSZERO同後代。ALIGN 失敗時回 [ALIGN] ERR ANG（後代是 ERR SPI）
LOG、LOGQ、LOGSEL、LOGC、LOGS、LOGX同後代，欄位編號、大小、比例相同。筆數 = 8192 ÷ 每筆 byte 數（預設 585 筆）；FOC 20 kHz，所以 div = 1 時 0.029 秒、div = 40 時 1.17 秒。[LOG] SEL 與 [LOG] BEGIN 的最後多一個 foc_hz=（後代也加了）。enc 欄位是 AS5600 讀值 × 16
SET / GET 的 PID（ID、IQ、VEL、POS）同後代。電流環（ID / IQ）的 D、RAMP 可以設，但這一代的定點電流環不使用
SPEED、MODE、ANGLE、MOVE、POSNOW、POSDIV同後代，但 MODE 只接受 0、1、5（5 = 力矩，這一代才有，開機預設）；POSDIV 以 4 為單位進位
IQREF這一代才有（第 6 節、10.2）。力矩模式的 Iq 命令（A）；其他模式下 SET IQREF 自動切到 MODE 5
POSTYPE、MIT.KP、MIT.KD、GET MIT這一代才有（第 6 節）。GET MIT 回 [PARAM] MIT KP=… KD=…
IDLOOP、BIAS1 / BIAS2、VELAW、VELB、IPHLPF / IPHTF、IDQLPF / IDQTF同後代
VELTF範圍 0 ~ 50 ms（後代 0 ~ 5 ms），預設 0.5 ms
CANID、CANRPT這一代才有（第 10.1 節）。SET 立即生效並寫進 EEPROM
I2C_SCAN掃 I2C1（EEPROM 那一條，找得到 0x50）；I2C2 正在連續讀 AS5600，不掃
ITEST、IT.QA / IT.QB / IT.DA / IT.DB、GET ITEST同後代（準位上限 1 A / 3 V、過電流 2 A、轉速 40 圈/秒 時結束）。half 以 FOC 中斷計，這一代是 20 kHz，所以上限 40000 是 2 秒（後代 1 秒）。準位由主迴圈換成定點數，測試中 SET 改準位最慢 5 ms 後生效。另外測試中 ALIGN 回 [ALIGN] BUSY
MT6835_CAL、EE_SAVE、EE_LOAD、EE_ERASE、ZERO_CLR、EE_RD、EE_WR、LIM_HERE、LIM_SPAN沒有，回 [CMD] UNKNOWN
RAT.*、LIM.*、NOF.*、PLAN.*、ENCC.*沒有，回 [PARAM] ERR PARAM
swd_cmd（SWD 寫入編號）只有 6（ALIGN）；其他編號回 [CMD] UNKNOWN
開機訊息[AS5600] STATUS=… AGC=… CONF=… ZPOS=… MPOS=…、[ZERO] ALIGN、[CAN] ID=… RPT=… EEPROM|DEFAULT、HAL_CAN1_Star1 is HAL_OK
故障訊息[ANG] ERR TIMEOUT + [OUT] COAST（角度逾時，關閉輸出）；[ANG] I2C RESET / [ANG] ERR I2C（I2C2 重新初始化成功 / 失敗）
